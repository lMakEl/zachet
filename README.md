# Зачёт

Сайт, который по загруженной лекции (PDF, PPTX, PPSX, DOCX) делает:

- тест с вариантами ответов: 20, 30 или 35 вопросов;
- тест «правильно / неправильно»: 20, 30 или 35 утверждений;
- озвученную анимированную лекцию.

Открыть: https://lmakel.github.io/zachet/. Кнопка «Открыть демо без ключа» показывает всё на готовом примере и не обращается к моделям.

## Как это устроено

1. Файл разбирается прямо в браузере: текст, таблицы и картинки по страницам. Страница почти без текста отправляется модели картинкой.
2. Языковая модель выписывает карту фактов с дословными цитатами. Код проверяет, что каждая цитата есть в лекции.
3. По фактам модель пишет вопросы. Место верного ответа и то, какие утверждения ложные, назначает код.
4. Вторая модель решает тест вслепую, не видя ключа. Спорные вопросы переделываются или выбрасываются.
5. Лекция состоит из коротких фраз: у каждой свой звук и свой элемент на экране, поэтому они появляются вместе.

Модели: Claude Sonnet 5.5 (факты, вопросы, сценарий), Claude Haiku 5.5 (слепая проверка), Gemini 3.8 Flash TTS (голос). Все вызовы идут через OpenRouter, идентификаторы лежат в `js/config.js`.

## Ключ и данные

Ключ OpenRouter создаётся входом по кнопке (потолок $5, срок 30 дней) и хранится только в браузере пользователя: до закрытия вкладки или, если стоит галочка «Запомнить», до выхода. Текст лекции отправляется в OpenRouter. Своего сервера у сайта нет.

## Запуск у себя

Сборка не нужна. Из папки проекта, Node 20 или новее:

```
node tools/dev-server.mjs 8123
```

Открыть http://localhost:8123/. Сторонние библиотеки и их лицензии: `vendor/VERSIONS.md`. Слайды демо: `tools/demo-lecture.html`.
